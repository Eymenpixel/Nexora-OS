# Nano Package for Kaya OS

## Description
GNU Nano text editor adapted for Kaya OS.

## Version
8.0

## Build Instructions
```bash
bash packages/nano/build.sh
```

## Usage
```bash
nano filename.txt
nano --version
```

## Features
- Clean version output (Kaya OS branding)
- Lightweight text editor
- Full GNU Nano functionality
