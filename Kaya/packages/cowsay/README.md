# Cowsay Package for Kaya OS

## Description
Cowsay generates an ASCII picture of a cow saying or thinking something.

## Version
3.7.0

## Build Instructions
```bash
bash packages/cowsay/build.sh
```

## Usage
```bash
cowsay "Hello from Kaya OS!"
echo "Kaya OS is awesome" | cowsay
cowsay -f dragon "Kaya OS"
cowthink "What a system!"
```

## Features
- ASCII art cow with customizable messages
- Multiple cow personalities (dragon, turtle, etc.)
- Cowthink variant for thoughts
- Text wrapping support
- Fun and nostalgic CLI experience
