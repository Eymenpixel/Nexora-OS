# Vim Package for Kaya OS

## Description
Vim is an advanced text editor that seeks to provide the power of the De-facto Unix editor Vi, with a more complete feature set.

## Version
9.0

## Build Instructions
```bash
bash packages/vim/build.sh
```

## Usage
```bash
vim filename.txt
vim +NNN filename.txt  # Open at line NNN
vim -d file1 file2     # Diff mode
vi filename            # Vi compatibility mode
```

## Features
- Advanced text editing capabilities
- Syntax highlighting
- Plugin support
- Customizable configuration
- Python3 integration
- Vi compatibility mode
