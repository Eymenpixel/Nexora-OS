# Screenfetch Package for Kaya OS

## Description
Screenfetch is a system information display tool that shows system specs alongside your distribution logo.

## Version
3.9.1

## Build Instructions
```bash
bash packages/screenfetch/build.sh
```

## Usage
```bash
screenfetch
screenfetch -A "Kaya OS"
screenfetch -D "Kaya"
```

## Features
- Displays system information (CPU, RAM, GPU, etc.)
- ASCII art distribution logo (custom Kaya OS design)
- Screenshot-like system overview
- Customizable themes
- Kaya OS branding
- Custom Kaya OS ASCII art logo included

## Files
- `build.sh` - Build script for compilation
- `README.md` - Package documentation
- `kaya-logo.txt` - Custom Kaya OS ASCII art logo
