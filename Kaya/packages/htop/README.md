# Htop Package for Kaya OS

## Description
Htop is an interactive system-monitor process-viewer and process-manager written in C.

## Version
3.2.2

## Build Instructions
```bash
bash packages/htop/build.sh
```

## Usage
```bash
htop
htop -u username
htop -p PID
```

## Features
- Real-time system monitoring
- Interactive process management
- CPU and memory usage visualization
- Process tree view
- Customizable display
- Color support
