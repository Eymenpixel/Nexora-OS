# Figlet Package for Kaya OS

## Description
Figlet is a program for making large ASCII text banners using large characters made of other characters.

## Version
2.2.5

## Build Instructions
```bash
bash packages/figlet/build.sh
```

## Usage
```bash
figlet "Kaya OS"
figlet -f banner "Welcome"
figlet -f slant "Hello"
echo "Kaya" | figlet
```

## Features
- Large ASCII text generation
- Multiple font styles
- Text alignment options
- Customizable character sets
- Perfect for welcome messages and headers
